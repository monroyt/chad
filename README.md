# Adictos al Progreso

Repo Next.js con TypeScript, React y Framer Motion para una lectura editorial animada y una segunda página audiovisual.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Assets

Coloca los archivos en `public/assets`:

- `bojackhorseman` como imagen
- `YT_AUTOMATION` como imagen
- `ENTERPRISE` como imagen
- `chad` como imagen
- `tevez` como audio (`mp3`, `ogg` o `wav`)

Las imágenes aceptan extensiones comunes: `png`, `jpg`, `jpeg`, `webp`, `gif` o `avif`.

## Deploy en Vercel

Vercel detecta Next.js automáticamente. Solo importa el repo y usa los comandos por defecto:

- Build command: `npm run build`
- Output: Next.js default
